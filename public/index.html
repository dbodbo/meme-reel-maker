Tutorial

Fazer um Reel

  1. Abra a aba Editor.
  2. Coloque o vídeo: cole o link do Reels no campo de cima e clique em Baixar (veja “Baixar pelo link” abaixo). Ou clique em Escolher vídeo, ou arraste o arquivo para o preview.
  3. Ajuste o vídeo: arraste no preview para mover e use o zoom para aumentar ou diminuir.
  4. Corte (opcional): dê Play, pare onde quer começar e clique em Início = atual. Faça o mesmo com Fim = atual.
  5. Texto (opcional): clique em + Texto, digite e arraste no preview.
  6. Barra (opcional): clique em + Barra para tampar uma parte do vídeo (por exemplo, uma legenda antiga). Arraste para mover e puxe as bordas para mudar o tamanho.
  7. Clique em Exportar Reel (MP4). O vídeo baixa no navegador e uma cópia fica na pasta output.

Tudo o que você posiciona (texto, barras, enquadramento) é salvo sozinho. Só o corte de tempo não é.

Baixar pelo link

  1. Cole o link no campo Cole o link do Reels e clique em Baixar. Funciona com Instagram, TikTok, YouTube, Facebook e X.
  2. O vídeo abre sozinho no editor. Uma cópia fica na pasta downloads.

Instagram: ele quase sempre pede login. Em Login (Instagram) escolha o navegador onde você está logado no Instagram (Chrome, Brave...) e baixe de novo.

O download do Instagram deu erro. O que fazer?
  • Mensagem sobre secretstorage: no terminal, rode pipx inject yt-dlp secretstorage.
  • “resposta vazia” ou “Failed to parse JSON”: atualize o downloader com pipx install --force --pip-args="--pre" yt-dlp e tente de novo.
  • Ainda não funcionou? Use o cookies.txt: no Chrome, com o Instagram aberto e logado, exporte os cookies com uma extensão como “Get cookies.txt LOCALLY” e salve o arquivo como cookies.txt na pasta do projeto. O programa usa esse arquivo sozinho.
  • Atenção: o cookies.txt dá acesso à sua conta. Não compartilhe e, se puder, use uma conta secundária.
  • Se nada der certo, baixe o vídeo de outro jeito e use Escolher vídeo.

Só na primeira vez: o downloader precisa estar instalado (pipx install yt-dlp).

Criar o template (foto, nome e @)

O template é a imagem que fica por cima do vídeo, com sua foto, nome, @usuário e selo de verificado. Para mudar:

  1. Abra a aba Criar template.
  2. Clique em Escolher foto e arraste dentro do círculo para enquadrar.
  3. Edite o nome e o usuário. Marque ou desmarque o selo de verificado.
  4. Clique em Usar no editor. Pronto: os próximos Reels já saem com esse template. (O template antigo fica guardado em data/backups.)
  5. Se quiser o arquivo, clique em Baixar PNG.

Se algo não funcionar

  • Uma aba nova não aparece ou dá erro: o programa precisa ser reiniciado. No terminal onde ele roda, aperte Ctrl+C e rode npm start de novo. Depois recarregue a página.
  • Para abrir o programa: terminal na pasta do projeto, npm start, e acesse http://localhost:3000.
